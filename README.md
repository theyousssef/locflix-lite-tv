# Locflix Lite

A small Android TV app that plays the movies and episodes shared to it from Locflix.

- **Fetch latest** (left menu) takes everything that was shared; it then appears in the list.
- OK plays (it resumes where you stopped); hold OK (or press Menu) removes an item.
- Items leave the list by themselves once 98% has been watched.

## Install

Download `locflix-lite-armeabi-v7a.apk` (most TVs) or `locflix-lite-arm64-v8a.apk` from the
[latest release](../../releases/latest) and install it. After that the app updates itself once a
day from this page; when it asks, allow it to install updates.
